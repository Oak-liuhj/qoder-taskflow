# 智能任务编排

面向 DeepSeek Harness 的智能任务编排插件（0.1.3），提供持久层级任务计划、按需子会话与完成通知。

## 环境要求

Node.js ≥24.9.0。宿主须启用 tools、agents、sessions、systemPrompt、subagents，并注册 `spawn` 子会话提供者；客户端需要会话、工作区和右侧栏服务。宿主兼容声明：`>=0.2.1-rc.3 <1.0.0-0 || >=0.2.2-0 <1.0.0-0 || >=0.2.3-0 <1.0.0-0 || >=0.3.0-0 <1.0.0-0`。声明范围与已运行测试的版本分别记录，具体见仓库验收记录。

## 使用方式

在主会话说明目标，模型根据复杂度创建独立于 `todo_write` 的任务计划。简单事项在负责会话内完成，复杂且独立的事项可创建子会话，在配置上限内继续生成孙子会话。有效结果立即完成事项并通知直接父会话，无父级审批环节。

后续消息只做增量变更，不覆盖原计划。新增事项默认挂到当前任务；主会话可明确指定父任务 ID 或唯一完整名称。修改要求后版本递增，旧执行结果失效。向已完成任务增补下级时会重新打开祖先并保留历史报告。

右侧直接显示层级清单。增补和修改会预填会话，发送后由模型执行；开始/继续按钮直接向主会话提交执行请求并显示结果，保留用户草稿。模型恢复原父子任务，已完成下级不重复执行；受阻原因直接展示，缺少外部输入时仍保持受阻。取消和同级排序可直接操作。左侧主会话下展示真实的多层子会话与重试历史，按实际直接父子地址打开。

示例：

```text
先规划知识库导入任务，复杂部分按需委派。
在 T-005 下新增一个移动端检查。
修改 T-003 的要求，增加 PDF 支持。
继续执行 T-003。
```

## 数据与工具

左侧会话列表使用原型的气泡/展开图标、状态圆点和层级连线。仅规划不创建子会话；行内事项开始执行后建立真实记录，委派事项获得执行名额后建立执行会话。嵌套行内子项挂在对应父事项的记录下，未执行事项不提前生成。旧版提前建立但未执行的记录保留数据并隐藏。每层中高复杂度事项执行前都由模型判断是否继续拆解，判断按任务版本保存，子事项同样可继续拆解孙事项。

输入框上方根据最新对话、任务状态及阻塞条件生成3–5条快捷回复。使用当前会话模型的额外请求，预留4096 tokens（含推理），最长等待60秒；同一上下文缓存，执行中等待，失败显示具体类别并可重试。点击将内容追加到草稿，保留已有文本与引用，确认后自行发送；quickReplies=false 可关闭。

账本默认位于 `${DSH_HOME}/taskflow`，未设置环境变量时为 `~/.dsh/taskflow`。同一目录只允许一个活跃写入者。停止宿主后备份整个目录，完整迁移还需备份原生 DSH 会话。中断任务恢复为暂停，需从负责会话继续。

浏览器、命令和编辑操作仍由宿主工具执行。Markdown、Excel、Word、PPT、PDF 自动使用宿主文档预览插件，集成到工具视图面板；多个文件逐项预览，无需选择文件或预览方式。预览随工具区调宽、悬浮、拖动和滚动，关闭时仅清理本次预览。Taskflow 不直接读取文档，读取权限、渲染和加载错误由宿主预览插件负责。浏览器工具返回的 HTTP(S) 地址交给宿主浏览器插件；不保证与第三方自动化浏览器共享登录状态或页面进度。文件识别来自成功工具结果的明确路径；终端未返回路径时，需用 taskflow_open_view 传入真实 filePath。插件缺失时显示原因，启用后可点击“重试打开”。

右上角图标加“任务”支持点击展开、再次点击收起。执行过程和关键结果保留在当前子任务会话，模型使用 taskflow_progress 保存阶段进展；行内事项写入记录子会话，委派事项写入执行子会话。最终结果保存成功后再通知直接父任务，不逐条发送过程通知。

工具区可拖宽或使用键盘调整，支持悬浮、拖动标题栏、调整悬浮大小及重新停靠，布局按会话保存。右侧事项及左侧子会话在真实执行时显示“进行中”和旋转图标，等待、受阻、暂停及完成时停止旋转；状态约每 1.2 秒同步。其他插件可注册专用渲染器。

工具视图仅保留紧凑标题栏，隐藏文件路径、重复打开和成功提示，文档预览填满剩余高度；多个文档纵向滚动查看。加载失败仍可重试。右侧待办清单在普通停靠模式默认300px，可拖动左边缘调整宽度并自动记住；窗口变窄时会自适应收窄，恢复后还原偏好。全屏、悬浮和其他插件页面继续使用宿主布局。推荐回复等待当前主任务结束或生成中时显示小型旋转图标和“正在推荐中...”，与推荐内容左边缘对齐；等待期间不会额外并发调用模型，完成或失败后停止。
